Project Overview

Objective

Build an AI system that accurately classifies chest X-rays as NORMAL or PNEUMONIA to assist medical diagnosis.

The Dataset

  • 5,856 chest X-ray images sourced from Kaggle

  • Binary classification task: Normal vs Pneumonia

  • Severe class imbalance:
    73% Pneumonia vs 27% Normal

Technical Stack

  • Implemented in Python with PyTorch framework

  • Jupyter Notebooks used for rapid experimentation and visualization

  • Optimized for CPU training (efficient architecture, no GPU required)
