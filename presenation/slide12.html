Technical Challenges & Solutions

Class Imbalance
Problem

Dataset has 3x more Pneumonia cases than Normal cases

Solution

Weighted loss function (Normal mistakes penalized 3x)

Small Validation Set
Problem

Original split had only 8 images per class (unreliable)

Solution

Created proper 20% stratified split from training data

Overfitting Risk
Problem

Baseline CNN showed significant train-validation gap

Solution

Transfer learning (ResNet18) generalizes better

>95%

Target Recall

Medical Safety Constraint:
Missing a pneumonia case is dangerous. We prioritized high recall to ensure patient safety.

Key Philosophy

"AI in medicine must be robust. We addressed data limitations systematically to build a safe, reliable diagnostic tool."
