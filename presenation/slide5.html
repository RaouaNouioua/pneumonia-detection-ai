Model 1 - Baseline CNN (From Scratch)

3-Layer CNN Architecture
Input
224×224×3
Block 1
Conv (3→16) ReLU + MaxPool
Block 2
Conv (16→32) ReLU + MaxPool
Block 3
Conv (32→64) ReLU + MaxPool
Classifier
Flatten Dense(128) + Drop
Output
Sigmoid 2 Classes

Key Features

  • ~6.5 million trainable parameters

  • Fully trained from scratch (random init)

  • Input resized to 224×224 pixels

Handling Imbalance

  • Class Weights: Penalize Normal mistakes ~3× more

  • Augmentation: Random horizontal flips during training

  • Dropout: 50% rate to reduce overfitting

Training Specs

  • Epochs: 10 total epochs

  • Time: ~15 minutes on standard CPU

  • Optimizer: Adam (LR = 0.001)
